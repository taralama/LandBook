# Landbook – Real Estate Platform

Landbook is a full-stack real estate platform built using the MERN stack. It simplifies the process of discovering, listing, buying, selling, and renting properties by connecting property owners, buyers, sellers, landlords, and tenants through a centralized platform.

## Tech Stack

- **MongoDB** – NoSQL database for storing application data.
- **Express.js** – Backend framework for building REST APIs.
- **React.js** – Frontend library for building the user interface.
- **Node.js** – JavaScript runtime for backend development.

## Features

### Property Listings
- Create and publish property listings.
- Add property details, descriptions, pricing, and images.
- Update and manage existing listings.
- Support properties available for sale and rent.

### Property Discovery
- Browse available properties.
- Search properties by location and keywords.
- Filter properties by price, type, and availability.
- View detailed property information.

### User Management
- User registration and authentication.
- Manage user profiles.
- Manage personal property listings.

### Property Management
- Update property information.
- Manage property availability and listing status.
- Upload and manage property images.
